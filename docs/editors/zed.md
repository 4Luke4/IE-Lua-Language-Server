# Zed

**Not supported yet.**

Zed only starts language servers that are registered by a Zed *extension*; its settings can
change the binary or options of such a server, but cannot add a new one
([Configuring Languages](https://zed.dev/docs/configuring-languages),
[Language Extensions](https://zed.dev/docs/extensions/languages)).

An IE Lua extension for Zed does not exist yet. If you would like one, please
[open a feature request](https://github.com/4Luke4/IE-Lua-Language-Server/issues/new?template=feature_request.yml).
